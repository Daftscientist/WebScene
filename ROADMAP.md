# Roadmap

## v1 (current foundation)

- Core timeline model (project/comp/layers/tracks)
- Canvas2D backend
- Asset registry + loaders
- Built-in effects
- Optional player module
- Frame export + manifest

## v1.5 (experimental)

- WebCodecs export path with muxer guide
- More effect optimizations and quality toggles
- Additional audio timeline utilities

## v2 (editor readiness)

- Web editor integration APIs
- Rich undo/redo history tools
- Graph/timeline inspection helpers
- Additional renderer backends (WebGL/WebGPU)
