# Governance

WebScene uses a lightweight maintainer model.

## Roles

- Maintainers: merge PRs, manage releases, enforce policies.
- Contributors: propose and implement improvements.

## Decision making

- Small technical changes: maintainer consensus in PR.
- Breaking API changes: documented proposal + migration notes.

## Release flow

- Semantic versioning.
- Changelog entries for user-facing behavior changes.
- CI must pass before merge/release.
